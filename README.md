# VeePN Growth Audit

**Live → https://eddieatadapty.github.io/veepn-flow-rebuild/**

Five ideas to turn more VeePN users into subscribers, each built into a clickable version of VeePN's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Put the proof where the decision happens | +10–15% CR to purchase |
| 02 | Make the yearly plan the obvious pick | +10–15% ARPU |
| 03 | Hold the permission prompts until there’s a reason | +10–15% CR to purchase |
| 04 | Ask one question, then use the answer | +10–20% CR to purchase |
| 05 | Let them hide their IP before they pay | +5–15% CR to purchase |

Every price, rating and feature comes from VeePN's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for VeePN. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
